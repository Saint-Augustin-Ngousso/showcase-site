# Paroisse Saint Augustin de Ngousso

Site de la paroisse Saint Augustin de Ngousso (Archidiocèse de Yaoundé, zone pastorale de l’Omnisport). Stack : React, Vite, Tailwind CSS.

Arborescence calquée sur le dossier de contenus du 3 novembre 2026 : huit rubriques, contenus officiels déjà connus, mentions « à préciser » là où l’équipe pastorale n’a pas encore transmis l’information.

## Lancer le site

```bash
npm install
npm run dev
```

Le serveur de développement s’ouvre sur `http://localhost:5173`.

## Rubriques

1. Accueil — slogan, thèmes, horaires, prochain événement, mot du curé
2. La paroisse — identité, histoire, programme pastoral 2026-2027
3. Nos prêtres — curé, vicaires, secteurs et aumôneries
4. Messes et sacrements — dimanche (chapelle et petite église), confessions, démarches
5. Secteurs et CEV — Saint Luc, Saint Marc, Saint Jean
6. Mouvements et services — 29 associations, chorales, jeunes, conseils, commissions
7. Agenda et actualités — lancement de l’année, récollections par métier
8. Contact et soutien — adresse, plan, secrétariat, dons

Pages secondaires : enseignements, prière, galerie (phase 2), recherche, confidentialité.
